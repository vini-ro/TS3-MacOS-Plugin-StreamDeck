English: Enter your TeamSpeak 3 ClientQuery API key for authentication. This is optional but recommended for secure connections.

You can find or generate your API key in TeamSpeak 3 under Tools → Options → Addons → ClientQuery.

Português: Insira sua chave API do TeamSpeak 3 ClientQuery para autenticação. Isso é opcional, mas recomendado para conexões seguras.

Você pode encontrar ou gerar sua chave API no TeamSpeak 3 em Ferramentas → Opções → Complementos → ClientQuery.
